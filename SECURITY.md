# Security policy

Please do not report vulnerabilities involving credentials, private NOTE content, or
handwritten.blog account access in a public issue. Email `hello@handwritten.blog` with a
concise description and reproduction steps.

The plugin never needs a Supernote Cloud credential. If any installation or website asks
for one, stop and report it.

Supported device and firmware combinations will be listed in the README. Development
builds outside that matrix are not supported.
